# Changelog

## v1.0.0

### Initial Release

- Added a real-time Practice Mode HUD.
- Added a practice attempt counter.
- Added an active checkpoint counter.
- Added current and best progress tracking.
- Added customizable Geode settings.
- Added automatic HUD visibility for Practice Mode.
- Added Windows support for Geometry Dash 2.2091.

### Compatibility

Built using Geode SDK 6.0.0-alpha.2.

### Notes

Practice Tools is designed to provide useful practice statistics without modifying gameplay physics or normal-mode completion records.
